04 / 实验结论

生成式栅格视频 vs 分析式矢量渲染

不是谁替代谁，而是两种完全不同的可控性 / 保真度取舍。

维度AI 生成短片矢量化 WebGL / WebGPU
输入与结果原图作为首帧，模型生成新像素从原图提取轮廓，重构路径与图元
数据体积— MP4，固定 5 秒— JSON + 程序化着色器
分辨率固定栅格分辨率，放大后受像素限制几何由着色器光栅化，可任意缩放 / DPR 适配
可编辑性基本不可编辑几何，只能重新生成控制点、颜色函数、描边、花蕊、动画均可参数化
确定性生成式结果含随机性，难以逐帧复现同一输入 + 同一参数 = 确定性输出
GPU 角色主要做视频解码与显示顶点变换、渐变、光晕、轮廓与网格全部实时计算
跨 API与渲染 API 基本无关同一几何数据分别写入 WebGL 与 WebGPU 管线
优势光影、材质和自然动态最接近原图质感轻量、可交互、可缩放、可导出 SVG，适合 UI / 实时图形
代价文件更大、不可控、可能引入形变或闪烁丢失精细纹理，需手工重建花蕊 / 渐变 / 描边等语义

AI 视频适合「表现」

保留玻璃质感、柔和阴影和自然高光，用最少人工得到一段有生命力的短片；代价是形状、镜头和逐帧像素由模型决定。

矢量 GPU 渲染适合「构造」

本实验真正把花朵拆成可计算的轮廓、路径与图元：240 次径向采样、RDP 简化、Catmull-Rom 细分、扇形网格，再以 GLSL / WGSL 双管线绘制。形状、颜色和运动都成为可调参数。

可继续深入

下一步可换成 Potrace 式多色区域追踪、SDF 轮廓抗锯齿、计算着色器粒子，或把 SVG 路径直接做 GPU 曲线细分。
